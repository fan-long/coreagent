# Core-Agent 平台说明

## 平台概述 {#overview}

Core-Agent 工程平台负责软件工程全生命周期实施过程中的资产组织与 AI 能力装配，不承载具体应用系统的业务逻辑。

平台按五个功能分组组织能力：

- 基础管理：项目信息、应用组件、应用类型、技术框架、Spec 模板与任务类型
- AI 能力配置：模型配置、通用 Agent 集成、Skill 配置、Agent 配置、工作流配置
- 组件公共资产：需求文档、交易接口设计、数据模型、测试案例、组件与系统特性、补充知识、代码参考
- 工程实施：工程仓库与工程配置、任务管理与流程执行、问题跟踪
- 通用能力：AI 辅助对话、消息留痕与变更提案

## 实施流程 {#workflow}

平台以「项目 → 应用组件 → 工程仓库 → 任务条目」为主线组织工程实施：

1. 在环境管理中维护项目、应用组件、技术框架与模板等基础配置；
2. 为组件关联需求规格组并指定主任务类型，菜单名称与可用入口随之确定；
3. 在组件信息中选定工程仓库，按任务类型执行任务与工作流；
4. 通过问题跟踪与工作台指标掌握实施进展。

## 导航与上下文

- 一级导航提供「工作台」与「环境管理」两个入口；
- 组件信息视图须先选定组件，再选定工程仓库，页面内容随两者变化；
- 顶栏展示当前项目与当前角色，角色仅用于展示，不约束功能可见性与操作权限；
- 不可用的功能入口以置灰加悬停提示呈现，提示中给出前置配置位置。
