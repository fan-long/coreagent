## 5. 发现的问题

### 5.1 【高】浅色令牌包的强调色系列取值为绿色，违反 RC-FT002-10 / RC-FT002-12

**证据**（`src/main/resources/static/css/tokens-light.css:27-30`，`src/main/resources/theme/light.json` 同值）：

```
--ca-color-accent-gold:       #29A36A   /* 绿，H=152.0° S=59.8% L=40.0% */
--ca-color-accent-gold-hover: #238C5B   /* 绿，H=152.0° */
--ca-color-accent-gold-dim:   #7DCAA1   /* 绿 */
--ca-color-accent-gold-soft:  rgba(41, 163, 106, 0.18)   /* 绿 */
```

**问题**：

1. 名为 `accent-gold` 的强调令牌在浅色包中**不是金色**。该令牌承载主操作按钮底色、当前导航项文字、关键指标数值、卡片图标等（`.button-primary`、`.primary-nav-item.is-active`、`.metric-value`…），即浅色主题下**主操作与当前导航项呈现为绿色**——与 RC-FT002-10「强调金仅可用于强调元素」及 RC-FT002-14「主操作与当前导航项使用强调金」不符。
2. **与语义成功色不可区分**：浅色包 `color-success = #1C7A4F`（H=152.6°），与 `accent-gold`（H=152.0°）**色相差仅 0.6°**，二者仅靠明度差（40.0% vs 29.4%）区分。RC-FT002-12 明确要求「语义状态色必须与强调金在视觉上可区分」——该条在浅色包下**不成立**。
3. **同族令牌自相矛盾**：暗色包 `accent-gold = #D4AF37`（金），打印包 `accent-gold = #7A5C12`（金，符合 D-016/C-02「金色压深为 #7A5C12」），**仅浅色包为绿**。打印包的语义色按 D-016/C-02 取自浅色基线，却自行给出金色强调值——两处对同一令牌名给出不同色相，侧证浅色包取值异常。

**范围与可达性**：浅色包经运维开关 `platform.theme.active=light` 可达（本次已实测返回 200），非默认路径，且受观察期（至 2026-10-02）约束。设计文档中**未出现** `#29A36A` 等取值，即该取值来自上一轮实现的建议值，未经设计交付确认——与设计阶段已登记的「令牌取值未固化」问题（见 §5.4）为同一根因。

**建议**：由设计交付确认浅色包的强调色取值。若浅色主题仍需保持「金」的语义，应改为金色系（如与打印包 `#7A5C12` 或暗色包 `#D4AF37` 同色相、按浅底适配明度）；若确为有意改为绿色系，则须同步修改令牌命名（`accent-gold` → 中性名）、RC-FT002-10/14 的措辞与 TC-15 的判定口径。**在取值固化前，TC-15 判定为未通过，相关 AC 不得判定为通过。**

### 5.2 【中】暗色包警告色与强调金色相接近

`color-warning = #E0A93B`（H=40.0° S=72.7% L=55.5%）与 `accent-gold = #D4AF37`（H=45.9° S=64.6% L=52.4°）色相差仅 **5.9°**。二者靠饱和度与明度区分，在 RC-FT002-12「语义状态色必须与强调金在视觉上可区分」下余量偏紧。建议在取值固化时一并复核，并明确「可区分」的量化标准（色相差 + 对比度阈值）。

### 5.3 【中】设计 D-007/C-01 与实现就「禁用态是否使用整体不透明度」不一致

### 5.5 【中】`static/_btn.txt` 游离文件处于硬编码门禁扫描范围之外

`src/main/resources/static/_btn.txt`（**已纳入版本控制**，1113 字节级别）是一段**被截断的 CSS 片段**（首行即 `a-space-1);`，内容与 `app.css`/`layout.css` 高度重合），位于 static 根目录、处于 Spring 默认静态资源映射范围内，但**未在 `index.html` 中引用**。
