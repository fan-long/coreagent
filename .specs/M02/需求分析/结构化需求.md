# M02 项目信息 —— 模块需求（OpenSpec 风格 · 能力基线 Spec）

> 用途：以 OpenSpec Spec 结构描述一个模块当前已具备的能力基线，作为技术设计、代码生成与测试验证的输入。
> 文档类型：Spec（现状基线）；跨模块的增量变更由「功能点（ft）」以 Change 方式另行表达，不写入本文档。
> 编写单位：一个模块一份文档；能力（Capability）是需求的最小可验收单元。
> 通用性说明：本模板为通用模板，不预设任何项目的功能域、分组枚举与模块划分；模块编号、模块名称、所属分组、应用组件标识均取自使用方的模块字典。

## 0. 元信息

| 字段 | 填写内容 | 说明 |

| 模块编号 | M02 | 平台模块字典中的唯一编号 |
| 模块名称 | 项目信息 | 与模块字典一致 |

## 1. 背景与目标

### 1.1 现状与问题

平台以项目信息作为全部配置的归属根：项目名称决定顶栏「当前项目」的显示，项目目标与项目范围被组装进「AI 应用组件设计」对话上下文，工程阶段则同时驱动工作流阶段定义、任务执行阶段与 Agent 一级分类。现状实现支持多项目（列表、新增、按 ID 读取、更新），但工程阶段以逗号分隔文本存储、无独立阶段实体，阶段改名依赖「同一次保存中恰好删除一个并新增一个」的启发式判定；阶段变更只同步 Agent 分类，不直接改写既有工作流阶段，工作流阶段在打开工作流配置页时由前端补齐并修正固定标记。

### 1.2 目标与成功标准

- 目标：项目名称、目标、范围与工程阶段可被唯一、清晰地维护，并对下游（工作流阶段、Agent 分类、AI 会话上下文）保持一致的投影。
- 成功标准：保存后顶栏项目名称即时更新；锁定阶段无法被删除或改名；新增阶段在同名 Agent 分类下可立即选择 Agent；阶段改名后原分类下的 Agent 归属不断链。

### 1.3 非目标（明确不做）

- 不维护应用组件与技术框架：见 M03 应用组件、M05 技术框架。
- 不维护工作流阶段、节点与 Agent 绑定：见 M11 工作流配置。
- 不维护 Agent 定义与提示词模板：见 M10 Agent 配置。
- 不定义项目级权限、审计与多租户隔离策略。

### 1.4 关键约束

- 「需求分析、技术设计、代码生成、知识沉淀」四个工程阶段为锁定阶段：不可删除、不可改名，服务端与前端双重校验。
- 工程阶段名称同时是 Agent 一级分类名称，两者必须保持同名同步。
- 项目名称最长 128 字符；工程阶段以英文逗号分隔存储，读写均做去空白与去重。
- 项目定义变更只影响新建的 AI 会话，既有会话保留创建时的上下文快照。

## 2. 领域术语表

| 术语 | 定义 | 来源/约束 |
|---|---|---|
| 项目信息 | 平台中一个项目的名称、目标、范围与工程阶段的集合 | 全部配置的归属根 |
| 项目名称 | 项目展示名，用于顶栏「当前项目」与组件规划提示 | 必填，最长 128 字符 |
| 项目目标 | 项目建设的业务目标与定位描述 | 可空，注入 AI 会话上下文 |
| 项目范围 | 项目覆盖的功能域、系统配置与管理范围描述 | 可空，注入 AI 会话上下文 |
| 工程阶段 | 项目研发的阶段序列，默认「需求分析、技术设计、代码生成、测试验证、知识沉淀」 | 驱动工作流阶段与任务执行阶段 |
| 锁定阶段 | 不可删除、不可改名的工程阶段 | 需求分析 / 技术设计 / 代码生成 / 知识沉淀 |
| Agent 分类 | Agent 的一级归类，与工程阶段同名 | 阶段新增建立分类；阶段改名迁移归属 |
| 当前项目 | 顶栏展示的项目上下文 | 由项目名称投影 |

## 3. 业务场景

- 场景描述：项目负责人初始化平台时定义项目名称、建设目标与覆盖范围，并按团队研发方式裁剪工程阶段；研发过程中调整阶段名称或补充阶段，使工作流与 Agent 分类跟随变化。
- 触发条件：平台首次使用、项目立项或调整、工程阶段变更、需要新建项目。
- 参与角色：项目架构师（维护）、业务分析人员（查看）、评审人员与审计人员（查看）。
- 主流程：进入「环境管理 / 项目配置 / 项目信息」→ 填写项目名称、项目目标、项目范围 → 维护工程阶段 → 保存配置 → 顶栏项目名称与 AI 会话上下文同步生效。
- 分支流程：新增项目；删除或改名非锁定阶段；新增阶段后在 Agent 配置中选择该分类的 Agent。

## 4. 业务规则与不变量

| 规则编号 | 规则内容 | 适用范围 | 违反应如何处理 |
|---|---|---|---|
| BR-M02-01 | 项目名称必填，最长 128 字符，前后空白被裁剪 | 新增、编辑 | 拒绝保存并提示「项目名称不能为空」或「项目名称不能超过128个字符」 |
| BR-M02-02 | 项目目标与项目范围为可空长文本，保存时裁剪前后空白，空串按空值存储 | 新增、编辑 | 不触发校验，按空值保存 |
| BR-M02-03 | 工程阶段以英文逗号分隔文本存储；读取为空或缺失时回落默认阶段「需求分析、技术设计、代码生成、测试验证、知识沉淀」 | 读取、保存 | 自动回落默认值，不报错 |
| BR-M02-04 | 锁定阶段「需求分析、技术设计、代码生成、知识沉淀」不可删除、不可改名 | 编辑 | 拒绝保存并提示「工程阶段「X」为锁定阶段，不可删除或改名」 |
| BR-M02-05 | 一次保存中恰好删除 1 个阶段且新增 1 个阶段时判定为阶段改名：将该阶段下全部 Agent 的一级分类归属迁移为新阶段名 | 编辑 | 自动迁移，Agent 归属不断链 |
| BR-M02-06 | 工程阶段派生的 Agent 分类不落 agent_category 表：新增或删除阶段均不写分类表，阶段同名分类由前端按当前项目工程阶段动态叠加展示 | 编辑、Agent 配置 | 不产生分类表记录，分类随阶段自适应 |
| BR-M02-07 | 新增项目时项目名称必填，主键自增；阶段为空时使用默认预设阶段 | 新增项目 | 名称缺失拒绝保存并提示「项目名称不能为空」 |
| BR-M02-08 | 读取项目信息时若不存在任何项目，自动创建默认项目行（名称「AI新一代核心系统」及默认目标、范围与阶段） | 查看 | 自动创建，不报错 |
| BR-M02-09 | 项目列表按项目 ID 升序返回；更新按请求携带的项目 ID 定位，缺省更新 ID 最小的首个项目 | 列表、编辑 | 指定 ID 不存在时提示「项目不存在：X」 |
| BR-M02-10 | 项目名称变更后顶栏「当前项目」显示与新建 AI 会话上下文同步更新；既有会话保留创建时的上下文快照 | 编辑、AI 对话 | 既有会话不追溯改写 |
| BR-M02-11 | 项目目标与项目范围注入「AI 应用组件设计」对话上下文，作为组件规划 Agent 的定位依据；需求规格关联等人工配置不注入 | AI 对话 | 上下文按项目定义组装 |
| BR-M02-12 | 工程阶段集合去重且保持输入顺序；阶段名称为空白的项被忽略 | 编辑 | 自动裁剪与去重 |

## 5. 能力规格（Capabilities & Expectations）

### CAP-M02-01 项目信息查看

- 目的：以单一页面呈现当前项目定义与工程阶段序列。
- 范围边界：只读展示；读取时若项目不存在则自动创建默认项目行。
- 关联规则：BR-M02-08、BR-M02-09
- 验收预期：
  - GIVEN 平台已存在项目 WHEN 打开项目信息页 THEN 展示项目名称、项目目标、项目范围与工程阶段列表，阶段按存储顺序编号展示
  - GIVEN 工程阶段字段为空 WHEN 打开项目信息页 THEN 展示默认五个阶段（需求分析、技术设计、代码生成、测试验证、知识沉淀）
  - GIVEN 平台不存在任何项目 WHEN 打开项目信息页 THEN 自动创建默认项目行并展示其定义，且不报错
  - 异常预期：GIVEN 读取接口不可用 WHEN 打开项目信息页 THEN 展示失败提示而不是空白表单

### CAP-M02-02 新增项目

- 目的：支持一个平台内承载多个项目。
- 范围边界：产生一条项目记录；不自动创建组件、工作流与 Agent。
- 关联规则：BR-M02-01、BR-M02-07
- 验收预期：
  - GIVEN 未填写项目名称 WHEN 保存 THEN 拒绝保存并提示「项目名称不能为空」
  - GIVEN 填写项目名称与目标、范围 WHEN 保存成功 THEN 新项目出现在项目列表，主键自增，阶段为默认预设阶段
  - GIVEN 未传工程阶段 WHEN 保存成功 THEN 项目阶段按默认预设阶段存储，Agent 分类列表按新项目的阶段动态叠加展示
  - 异常预期：GIVEN 保存请求失败 WHEN 提交 THEN 客户端不新增本地项目记录并提示失败原因

### CAP-M02-03 编辑项目信息

- 目的：维护项目的可变属性并即时投影到顶栏与 AI 上下文。
- 范围边界：可修改名称、目标、范围与工程阶段；不改变项目 ID 归属。
- 关联规则：BR-M02-01、BR-M02-02、BR-M02-09、BR-M02-10
- 验收预期：
  - GIVEN 项目名称超过 128 字符 WHEN 保存 THEN 拒绝保存并提示「项目名称不能超过128个字符」
  - GIVEN 修改项目名称或目标、范围 WHEN 保存成功 THEN 顶栏「当前项目」立即更新，新建 AI 会话上下文使用最新值
  - GIVEN 项目目标与范围被清空 WHEN 保存成功 THEN 按空值存储，页面展示为空且不报错
  - 异常预期：GIVEN 请求携带的项目 ID 不存在 WHEN 保存 THEN 拒绝并提示「项目不存在：X」

### CAP-M02-04 工程阶段定义

- 目的：让工程阶段贴合团队研发方式，同时保证锁定阶段不被破坏。
- 范围边界：可新增、删除、调整非锁定阶段；锁定阶段只读且无删除入口。
- 关联规则：BR-M02-03、BR-M02-04、BR-M02-12
- 验收预期：
  - GIVEN 阶段列表包含锁定阶段 WHEN 查看阶段表 THEN 锁定阶段以只读加粗文本展示且无删除按钮
  - GIVEN 保存时缺少任一锁定阶段 WHEN 提交 THEN 拒绝保存并提示「工程阶段「X」为锁定阶段，不可删除或改名」
  - GIVEN 新增一个非锁定阶段 WHEN 保存成功 THEN 阶段按输入顺序保存，Agent 配置的分类列表随即出现该阶段分类
  - GIVEN 删除一个非锁定阶段 WHEN 保存成功 THEN 阶段被移除，该阶段分类不再出现在分类列表（分类表无记录）
  - 异常预期：GIVEN 阶段名称前后含空白 WHEN 保存成功 THEN 自动裁剪并去重，不产生重复阶段

### CAP-M02-05 阶段变更同步 Agent 分类

- 目的：保证「阶段名 = Agent 分类名」的对应关系在阶段调整后仍然成立。
- 范围边界：仅同步分类与 Agent 归属；不改写工作流阶段的节点与 Agent 绑定。
- 关联规则：BR-M02-05、BR-M02-06
- 验收预期：
  - GIVEN 同一次保存中删除 1 个阶段并新增 1 个阶段 WHEN 保存成功 THEN 原分类下全部 Agent 的一级分类归属迁移为新阶段名，分类列表由阶段序列动态派生
  - GIVEN 新增阶段 WHEN 保存成功 THEN 不写分类表，分类列表按最新阶段序列展示
  - GIVEN 删除阶段 WHEN 保存成功 THEN 分类表无记录需清理，Agent 归属保持不变
  - 异常预期：GIVEN Agent 归属迁移过程中失败 WHEN 保存 THEN 阶段与分类保持变更前状态，不出现阶段已改名而 Agent 未迁移的半完成状态

### CAP-M02-06 项目上下文注入 AI 对话

- 目的：让 AI 在组件规划设计时理解项目定位与阶段划分。
- 范围边界：注入项目名称、目标、范围与阶段文本；不注入人工维护的配置字段。
- 关联规则：BR-M02-10、BR-M02-11
- 验收预期：
  - GIVEN 项目已填写目标与范围 WHEN 新建「AI 应用组件设计」会话 THEN 会话首条上下文包含项目名称与项目目标，并在存在阶段时附带阶段说明
  - GIVEN 修改项目目标 WHEN 新建会话 THEN 新会话使用修改后的目标；既有会话内容不变
  - 异常预期：GIVEN 项目目标为空 WHEN 新建会话 THEN 上下文跳过该字段，不注入空占位文本

## 6. 界面规格

### UI-M02-01 项目信息页

- 位置与入口：环境管理 / 项目配置 / 项目信息
- 页面标题与说明：标题「项目信息」；说明「配置项目名称、目标、范围与工程阶段；项目名称用于顶栏「当前项目」显示，并生成组件规划Agent的定位提示」
- 主操作：「保存配置」
- 元素清单：提示条（项目定义会组装进「AI应用组件设计」对话的当前上下文，目标与范围随对话发送给组件规划Agent；修改后新建会话立即生效）；项目名称输入框（maxlength=128）；项目目标多行文本；项目范围多行文本；「项目工程阶段定义」表格（序号、阶段名称、操作）
- 交互规则：锁定阶段展示为只读加粗文本且无删除按钮；非锁定阶段可编辑、可删除；可新增阶段
- 状态与反馈：保存成功后顶栏项目名称立即更新；校验失败按 §4 提示文案反馈

### UI-M02-02 工程阶段表格

- 位置与入口：项目信息页中部
- 主操作：「新增阶段」（表格上方）、行内「删除阶段」
- 元素清单：序号徽标（两位补零）、阶段名称（锁定阶段只读 / 其余为输入框）、删除按钮
- 交互规则：删除非锁定阶段即时从表格移除；锁定阶段行不渲染删除按钮与输入框
- 状态与反馈：保存时后端二次校验锁定阶段，缺失即拒绝并提示

### UI-M02-03 操作反馈与提示

- 元素清单：名称校验「项目名称不能为空」「项目名称不能超过128个字符」；锁定阶段「工程阶段「X」为锁定阶段，不可删除或改名」；项目不存在「项目不存在：X」；保存成功提示
- 状态与反馈：以浮动提示形式给出，不阻断页面其它操作

### UI-M02-04 顶栏当前项目

- 位置与入口：全局顶栏
- 元素清单：当前项目名称、项目切换入口
- 交互规则：项目名称保存成功后即时刷新
- 状态与反馈：项目数量为 0 时展示默认项目名称

## 7. 业务对象与属性

| 对象 | 关键属性 | 业务含义 | 必填 | 取值与约束 |
|---|---|---|---|---|
| 项目信息 | 项目ID | 项目唯一标识 | 是 | 自增主键，系统生成 |
| 项目信息 | 项目名称 | 项目展示名 | 是 | 最长 128 字符，前后空白裁剪 |
| 项目信息 | 项目目标 | 项目建设的目标与定位 | 否 | 长文本，可空 |
| 项目信息 | 项目范围 | 项目覆盖的功能域与管理范围 | 否 | 长文本，可空 |
| 项目信息 | 工程阶段 | 项目研发阶段序列 | 否 | 英文逗号分隔文本；去空白、去重；为空回落默认五阶段；锁定阶段必须存在 |

派生展示信息（不单独存储）：顶栏「当前项目」名称、阶段序号、阶段数量。

## 8. 依赖与复用关系

- 上游：M01 工作台与全局导航（顶栏项目上下文）、M27 AI 辅助对话（会话上下文组装）
