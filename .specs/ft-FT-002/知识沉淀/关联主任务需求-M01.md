# M01 工作台与全局导航 —— 模块需求（OpenSpec 风格 · 能力基线 Spec）

> 用途：以 OpenSpec Spec 结构描述一个模块当前已具备的能力基线，作为技术设计、代码生成与测试验证的输入。
> 文档类型：Spec（现状基线）；跨模块的增量变更由「功能点（ft）」以 Change 方式另行表达，不写入本文档。
> 编写单位：一个模块一份文档；能力（Capability）是需求的最小可验收单元。
> 通用性说明：本模板为通用模板，不预设任何项目的功能域、分组枚举与模块划分；模块编号、模块名称、所属分组、应用组件标识均取自使用方的模块字典。

## 1. 背景与目标

### 1.1 现状与问题

平台已实现统一入口与全局导航：工作台以组件卡片呈现当前项目概览，环境管理与组件信息分别以二级导航组织功能页面，顶栏提供当前项目切换、角色切换与平台说明入口。现状问题：角色切换仅改变展示，不约束功能权限；部分导航入口依赖组件配置或工程能力，不可用时仅置灰提示。

### 1.2 目标与成功标准

- 目标：让使用者在任意时刻都能明确「当前处于哪个项目、哪个组件、哪个工程、哪个页面」，并快速到达目标功能。
- 成功标准：从工作台或环境管理出发，三步内可到达任一模块页面；不可用入口均能说明原因与前置配置位置。

### 1.3 非目标（明确不做）

- 不实现功能权限与操作审计：平台尚未具备该能力。
- 不承载各功能页面内部逻辑：见对应模块。
- 不提供全局检索：平台尚未具备该能力。

### 1.4 关键约束

- 导航结构为两层：一级导航（工作台、环境管理）与二级导航（环境管理分组、组件信息分组）。
- 组件信息视图必须先选定组件，页面内容随所选组件与工程仓库变化。
- 菜单名称与可用性依赖组件配置（需求规格、主任务类型）与工程框架能力。

## 2. 领域术语表

| 术语 | 定义 | 来源/约束 |
|---|---|---|

| 环境管理 | 承载项目配置、知识库管理、系统配置、模板管理的功能区域 | 见 M02–M11 |
| 组件信息 | 选定组件后的功能区域，承载工程仓库、任务、编排、规则库、问题与组件公共资产 | 见 M12–M26 |
| 一级导航 | 顶栏的工作台与环境管理两个入口 | 决定是否展示二级导航 |
| 二级导航 | 按功能分组的侧边栏菜单 | 环境管理与组件信息两套 |

## 3. 业务场景

- 场景描述：使用者进入平台后，先从工作台了解当前项目有哪些组件及其健康状态，再进入某个组件查看任务、问题与资产；或直接进入环境管理维护项目与平台配置。
- 触发条件：登录平台、切换项目、从工作台进入组件、在环境管理与组件信息之间往返。
- 参与角色：全部角色。
- 主流程：进入平台 → 工作台查看组件卡片 → 点击组件卡片进入组件信息 → 在组件信息内切换工程仓库并选择功能菜单。
- 分支流程：切换当前项目；进入环境管理维护配置；打开平台说明；在组件信息内切换组件（返回工作台或切换项目）。

## 4. 业务规则与不变量

| 规则编号 | 规则内容 | 适用范围 | 违反应如何处理 |
|---|---|---|---|

| BR-M01-02 | 未启用组件在工作台卡片置灰，但仍可点击进入组件信息 | 工作台 | 允许进入，不额外拦截 |
| BR-M01-03 | 环境管理二级导航按「项目配置、知识库管理、模板管理、系统配置」四组固定顺序展示，组内页面固定：项目配置（项目信息、应用组件、技术框架）、知识库管理（系统特性）、模板管理（应用类型、Spec模板）、系统配置（模型配置、通用Agent集成、Skill配置、Agent配置、工作流配置） | 环境管理 | 分组顺序与组内页面固定，不随配置变化 |
| BR-M01-04 | 组件信息二级导航自上而下固定为：组件上下文（图标、名称、工程仓库数量、工程仓库管理入口）、工程仓库选择器、工程维度菜单（任务管理、服务编排全景、规则库全景、问题跟踪、代码库）、组件公共资产四类子分组（需求文档、设计资产、测试资产、知识库） | 组件信息 | 组件无工程仓库时不展示工程维度菜单，改为提示先创建工程仓库 |
| BR-M01-05 | 需求文档菜单名称取组件关联需求规格（Spec 组）的名称，未关联规格时使用默认名称「传统软件需求」，并以悬停说明展示「需求规格：{名称}」 | 组件信息 | 按组件配置动态展示 |
| BR-M01-06 | 接口设计与测试案例菜单名称由组件主任务类型的名称加固定后缀组成（如「模块接口设计」「模块测试案例」）；数据模型菜单名称固定为「组件数据模型」，不随主任务类型变化；未设置主任务类型时接口设计与测试案例菜单名称不含类型前缀 | 组件信息 | 按组件配置动态展示 |
| BR-M01-07 | 接口定义与数据模型入口仅在对应任务类型已配置 Agent 时可用 | 组件信息 | 置灰并通过悬停提示指引配置位置 |
| BR-M01-08 | 服务编排全景入口仅在当前工程的应用开发框架支持编排模式时可用 | 组件信息 | 置灰并提示框架不支持 |
| BR-M01-09 | 规则库全景入口仅在当前工程的基础技术框架支持规则库模式时可用 | 组件信息 | 置灰并提示框架不支持 |
| BR-M01-10 | 角色切换仅改变展示，不约束功能可见性与操作权限 | 顶栏 | 不产生权限效果 |
| BR-M01-11 | 同一时刻仅展示一个功能页面 | 全局 | 页面切换即替换主区域内容 |
| BR-M01-12 | 切换工程仓库后，任务管理、代码库、问题跟踪等工程维度内容随之切换 | 组件信息 | 按当前工程仓库重新加载 |
| BR-M01-13 | 全平台功能页面头部统一为「面包屑 + 页面标题 + 一句功能说明 + 右侧主操作按钮组」四段结构 | 全局 | 缺项按统一结构补齐 |
| BR-M01-14 | 以 Markdown 承载的文档类页面统一渲染正文并提供右侧固定提纲，提纲与正文由同一份内容派生，点击提纲定位对应章节 | 全局文档类页面 | 内容缺失时展示空态，不报错 |
| BR-M01-15 | 二级导航菜单项可展示数量角标，口径为该菜单对应资产数量或待处理数量 | 环境管理、组件信息 | 角标口径与对应模块一致 |

## 5. 能力规格（Capabilities & Expectations）

### CAP-M01-01 工作台组件概览

- 目的：集中呈现当前项目下的组件全貌与健康指标。
- 范围边界：只读派生视图；数据来源为 M03 与工程仓库、问题、规则库口径。
- 关联规则：BR-M01-01、BR-M01-02
- 验收预期：
  - GIVEN 当前项目存在若干组件 WHEN 进入工作台 THEN 以卡片网格展示全部组件
  - GIVEN 查看某卡片 WHEN 展示 THEN 含组件图标、名称、状态、功能范围与三项指标（阻塞事项数、任务数量、规则数量）
  - GIVEN 某组件未设置主任务类型 WHEN 查看任务数量指标 THEN 不展示具体口径名称，仅展示占位
  - GIVEN 某组件存在默认工程 WHEN 查看卡片底部 THEN 展示需求规格、工程数量与默认工程版本
  - GIVEN 存在未启用组件 WHEN 查看卡片 THEN 该卡片置灰且排在启用组件之后

### CAP-M01-02 从工作台进入组件信息

- 目的：由组件概览直达该组件的功能区域。
- 范围边界：改变导航上下文，不修改数据。
- 关联规则：BR-M01-02
- 验收预期：
  - GIVEN 点击启用状态组件卡片 WHEN 进入成功 THEN 侧边栏切换为该组件的组件信息导航，并默认选中该组件的默认工程仓库
  - GIVEN 点击未启用组件卡片 WHEN 进入 THEN 仍进入该组件的组件信息
  - GIVEN 工作台点击「管理组件」 WHEN 跳转 THEN 进入应用组件页

### CAP-M01-03 一级导航切换

- 目的：在工作台与环境管理之间切换。
- 范围边界：只切换视图，不改变数据。
- 关联规则：BR-M01-11
- 验收预期：
  - GIVEN 当前在工作台 WHEN 切换到环境管理 THEN 展示环境管理二级导航并进入项目信息页
  - GIVEN 当前在环境管理 WHEN 切换到工作台 THEN 隐藏二级导航并展示工作台

### CAP-M01-04 环境管理二级导航

- 目的：按功能分组组织平台配置类页面。
- 范围边界：导航与路由；页面内容由各模块实现。
- 关联规则：BR-M01-03
- 验收预期：
  - GIVEN 进入环境管理 WHEN 查看侧边栏 THEN 依次展示项目配置（项目信息、应用组件、技术框架）、知识库管理（系统特性）、模板管理（应用类型、Spec模板）、系统配置（模型配置、通用Agent集成、Skill配置、Agent配置、工作流配置）
  - GIVEN 点击某二级导航项 WHEN 切换成功 THEN 主区域展示对应页面且该项高亮
  - 异常预期：GIVEN 页面依赖的数据加载失败 WHEN 打开页面 THEN 保留页面结构并提示失败，不白屏

### CAP-M01-05 组件信息二级导航与工程仓库切换

- 目的：在选定组件与工程仓库的上下文中组织功能入口。
- 范围边界：导航、上下文切换与入口可用性判定；不实现各功能页面。
- 关联规则：BR-M01-04、BR-M01-05、BR-M01-06、BR-M01-07、BR-M01-08、BR-M01-09、BR-M01-12
- 验收预期：
  - GIVEN 已进入某组件 WHEN 查看侧边栏 THEN 顶部展示组件图标、名称、工程仓库数量与工程仓库管理入口，其下提供工程仓库选择器（选项为「工程名称-版本号(默认)」）
  - GIVEN 组件存在多个工程仓库 WHEN 切换选择器 THEN 工程维度页面内容按新工程重新加载
  - GIVEN 查看功能菜单 WHEN 展示 THEN 工程维度含任务管理、服务编排全景、规则库全景、问题跟踪、代码库；组件公共资产按需求文档、设计资产（接口设计、组件数据模型）、测试资产（测试案例）、知识库（组件特性、补充知识、代码参考、反思迭代）四类子分组展示
  - GIVEN 组件已关联需求规格 WHEN 查看需求文档菜单 THEN 菜单名称为该规格名称，未关联时为「传统软件需求」
  - GIVEN 组件已设置主任务类型 WHEN 查看接口设计或测试案例菜单 THEN 菜单名称按该任务类型名称加固定后缀命名；数据模型菜单始终为「组件数据模型」
  - 异常预期：GIVEN 当前工程的应用开发框架不支持编排模式 WHEN 查看服务编排全景入口 THEN 入口置灰并提示框架不支持

### CAP-M01-06 当前项目切换

- 目的：在同一平台内切换项目上下文。
- 范围边界：切换全局数据范围；不修改项目数据本身。
- 关联规则：无（本能力为导航或展示类行为，不直接承载业务规则）
- 验收预期：
  - GIVEN 点击顶栏当前项目名称 WHEN 弹窗打开 THEN 列表展示全部项目，当前项目标记「当前」且无切换按钮
  - GIVEN 选择另一项目 WHEN 切换成功 THEN 顶栏项目名称更新，工作台与各页面按新项目加载数据
  - GIVEN 在弹窗中新增项目 WHEN 名称合法且不重复 THEN 项目创建成功并出现在列表
  - GIVEN 在弹窗中编辑项目名称 WHEN 保存 THEN 列表与顶栏同步更新
  - 异常预期：GIVEN 项目名称为空 WHEN 保存 THEN 拒绝保存并提示

### CAP-M01-07 实施说明与平台说明

- 目的：说明平台在软件工程各阶段的实施定位与 AI 职责，并提供平台功能说明文档的查阅。
- 范围边界：只读展示；阶段表的输出内容可跳转到对应功能页面；不修改任何数据。
- 关联规则：BR-M01-14
- 验收预期：
  - GIVEN 点击顶栏「?」 WHEN 进入 THEN 展示实施说明页且隐藏二级导航
  - GIVEN 停留在「平台功能定位」页签 WHEN 查看 THEN 以表格展示九个实施阶段（架构设计、应用设计、软需分析、技术设计、代码开发、测试验证、知识沉淀、交付归档、运维与维护）的工作项、核心问题、参考资产、输出内容与 AI 职责，AI 职责分为自主、主导、辅助、暂不涉及四类
  - GIVEN 查看阶段表的「输出内容」 WHEN 点击某项 THEN 跳转到该输出对应的功能页面
  - GIVEN 切换到「平台功能说明」页签 WHEN 查看 THEN 从平台文档接口读取说明 Markdown，以左侧提纲、右侧正文渲染，点击提纲定位对应章节且当前章节高亮
  - 异常预期：GIVEN 平台功能说明文档缺失 WHEN 打开页签 THEN 提示暂无文档，不报错
  - 异常预期：GIVEN 平台功能说明文档读取失败 WHEN 打开页签 THEN 展示失败原因，不白屏

### CAP-M01-08 角色切换

- 目的：在顶栏标示当前使用者视角。
- 范围边界：仅展示；不产生权限效果。
- 关联规则：BR-M01-10
- 验收预期：
  - GIVEN 打开顶栏角色下拉 WHEN 查看选项 THEN 含项目架构师、业务分析人员、评审人员、审计人员
  - GIVEN 切换角色 WHEN 切换完成 THEN 顶栏显示新角色，功能可见性与操作权限不变

### CAP-M01-09 全局界面约定

- 目的：统一全平台的页面头部、文档阅读与导航角标表现，保证跨模块体验一致。
- 范围边界：全局表现约定，不改变各模块业务逻辑与数据。
- 关联规则：BR-M01-13、BR-M01-14、BR-M01-15
- 验收预期：
  - GIVEN 打开任一功能页面 WHEN 查看页面头部 THEN 依次展示面包屑、页面标题、一句功能说明与右侧主操作按钮组
  - GIVEN 处于组件上下文 WHEN 查看面包屑 THEN 形如「{组件名称} / {资产分组}」；处于环境管理 WHEN 查看面包屑 THEN 形如「环境管理 / {导航分组}」
  - GIVEN 打开以 Markdown 承载的文档类页面 WHEN 查看 THEN 正文统一渲染并展示右侧固定提纲，点击提纲定位章节且当前项高亮
  - GIVEN 浏览列表类页面 WHEN 鼠标悬停表格行 THEN 该行高亮
  - GIVEN 进入流程详情页 WHEN 查看头部 THEN 以面包屑展示所处流程位置，不提供整页返回按钮
  - GIVEN 查看二级导航 WHEN 该菜单存在数量口径 THEN 展示数量角标

## 6. 界面规格

### UI-M01-01 顶栏

- 位置与入口：平台所有非说明页顶部
- 页面标题与说明：左侧平台标识与名称；中部当前项目名称；右侧平台说明按钮与角色下拉
- 主操作：一级导航「工作台」「环境管理」
- 元素清单：平台标识、平台名称、当前项目名称（可点击）、一级导航按钮、平台说明按钮「?」、角色下拉
- 交互规则：点击当前项目名称打开项目列表弹窗；点击一级导航切换视图
- 状态与反馈：当前一级导航项高亮

### UI-M01-02 工作台

- 位置与入口：一级导航「工作台」
- 页面标题与说明：面包屑为「当前项目名称 / 工作台」，标题为「应用组件」，说明为「当前项目组件基线及默认工程概览」
- 主操作：「管理组件」
- 元素清单：组件卡片网格；卡片含图标、名称、状态标记、功能范围、三项指标、需求规格、工程数量与默认工程版本
- 交互规则：点击卡片进入组件信息；未启用卡片置灰但可点击
- 状态与反馈：无组件时卡片区为空

### UI-M01-03 环境管理侧边栏

- 位置与入口：一级导航「环境管理」
- 元素清单：项目配置（项目信息、应用组件、技术框架）、知识库管理（系统特性）、模板管理（应用类型、Spec模板）、系统配置（模型配置、通用Agent集成、Skill配置、Agent配置、工作流配置）
- 交互规则：点击导航项切换页面
- 状态与反馈：当前页面导航项高亮

### UI-M01-04 组件信息侧边栏

- 位置与入口：从工作台或其他入口进入某组件
- 元素清单：组件图标与名称、工程仓库数量、工程仓库管理入口；工程仓库选择器；工程维度菜单（任务管理、服务编排全景、规则库全景、问题跟踪、代码库）；组件公共资产子分组（需求文档、设计资产、测试资产、知识库）及各自菜单
- 交互规则：切换工程仓库后工程维度内容随之切换；置灰入口不可点击
- 状态与反馈：不可用入口悬停提示原因与前置配置位置；菜单可展示数量角标

### UI-M01-05 实施说明页

- 位置与入口：顶栏「?」
- 页面标题与说明：页签「平台功能定位」「平台功能说明」
- 主操作：页签切换
- 元素清单：阶段表（阶段、工作项、核心问题、参考资产、输出内容、AI 职责）；说明文档提纲与正文
- 交互规则：点击阶段表「输出内容」跳转对应功能页面；点击提纲定位章节，当前章节高亮
- 状态与反馈：加载中提示「正在加载平台功能说明…」；文档缺失提示「暂无平台功能说明文档」；读取失败提示失败原因

### UI-M01-06 项目切换弹窗

- 位置与入口：顶栏当前项目名称
- 页面标题与说明：标题「项目列表」；说明「点击行首按钮切换当前项目；点击编辑后可修改项目名称」
- 主操作：「新增项目」
- 元素清单：列表列（切换按钮或「当前」徽标、项目名称、操作）、编辑态输入框与保存取消
- 交互规则：点击行首按钮切换项目；点击编辑进入名称编辑态
- 状态与反馈：空态提示「暂无项目，点击下方「新增项目」添加」

### UI-M01-07 页面头部与文档阅读约定

- 位置与入口：全部功能页面
- 页面标题与说明：面包屑（组件名称或「环境管理」+ 分组）+ 页面标题 + 一句功能说明
- 主操作：该页面的主操作按钮组（可为空）
- 元素清单：面包屑、标题、功能说明、主操作区；文档类页面额外含右侧固定提纲
- 交互规则：点击面包屑上级可返回该层；点击提纲定位章节并高亮当前章节
- 状态与反馈：数据加载失败时保留页面结构并提示失败，不白屏

## 7. 业务对象与属性

| 对象 | 关键属性 | 业务含义 | 必填 | 取值与约束 |
|---|---|---|---|---|
| 组件卡片（派生视图） | 组件名称、组件图标、组件状态、功能范围 | 卡片主信息 | 是 | 来自 M03 应用组件 |
| 组件卡片（派生视图） | 阻塞事项数 | 当前工程打开状态问题数 | 是 | 派生计算 |
| 组件卡片（派生视图） | 任务数量 | 主任务类型对应任务数 | 是 | 派生计算，未设主任务类型时不展示口径名称 |
| 组件卡片（派生视图） | 规则数量 | 默认工程规则库口径规则数 | 是 | 派生计算，工程不可用时为 0 |
| 组件卡片（派生视图） | 需求规格名称、工程数量、默认工程版本 | 卡片底部信息 | 否 | 派生计算 |
| 导航项 | 导航分组、导航名称、导航图标、入口条件 | 二级导航菜单定义 | 是 | 分组顺序固定；名称与可用性可动态变化 |
| 角色（展示对象） | 角色名称 | 顶栏当前角色 | 是 | 项目架构师 / 业务分析人员 / 评审人员 / 审计人员 |
| 实施阶段（展示对象） | 阶段名称、工作项、核心问题、参考资产、输出内容、AI 职责 | 实施说明页的阶段能力表 | 是 | 九个阶段固定；AI 职责取自主 / 主导 / 辅助 / 暂不涉及 |

派生展示信息（不单独存储）：组件卡片的全部指标与底部信息。

## 8. 依赖与复用关系

- 上游：M02 项目信息（当前项目与工程阶段）、M03 应用组件（卡片数据源）、M21 工程仓库与工程配置（工程选择与框架能力）、M06 Spec模板与任务类型（菜单命名）

## 9. 异常、边界与失败模式

| 场景 | 处理要求 | 关联能力/规则 |
|---|---|---|
| 组件未启用 | 卡片置灰但仍可进入 | CAP-M01-01、CAP-M01-02、BR-M01-02 |
| 工程应用开发框架不支持编排模式 | 服务编排全景入口置灰并提示 | CAP-M01-05、BR-M01-08 |
| 工程技术框架不支持规则库模式 | 规则库全景入口置灰并提示 | CAP-M01-05、BR-M01-09 |
| 接口定义或数据模型任务类型未配置 Agent | 入口置灰并指引配置位置 | CAP-M01-05、BR-M01-07 |
| 项目名称为空或重复 | 拒绝保存并提示 | CAP-M01-06 |
| 说明文档缺失 | 展示空内容，不报错 | CAP-M01-07 |
| 平台功能说明文档读取失败 | 展示失败原因，不白屏 | CAP-M01-07、BR-M01-14 |
| 页面依赖数据加载失败 | 保留页面结构并提示失败 | CAP-M01-04 |
