## 1. 背景与目标

### 1.1 现状与问题

模型配置是平台全部 AI 能力的模型字典：Agent 配置、通用 Agent 集成的模型下拉选项均取自本模块，模型条目同时携带 Anthropic 与 OpenAI 两类 BASE_URL 以及前端、后端两套 ApiKey，用于区分浏览器侧调用与服务端调用的凭据。现状问题：ApiKey 以明文入库、界面按「前 3 位 + 后 4 位」掩码展示，提交掩码值视为未修改，属于防误覆盖的保护措施而非加密存储；模型条目被下游引用后删除不做事先校验。

### 1.2 目标与成功标准

- 目标：集中维护模型的标识、端点与凭据，作为 Agent 与集成配置的唯一模型来源。
- 成功标准：新增模型后立即可在 Agent 配置与通用 Agent 集成的模型下拉中被选择；未修改 ApiKey 时保存不会覆盖原值。

### 1.3 非目标（明确不做）

- 不维护 Agent 定义与提示词：见 M10 Agent 配置。
- 不维护通用 Agent 工具的 CLI 路径与环境变量：见 M08 通用Agent集成。
- 不实现调用计量、配额与成本统计。
- 不提供 ApiKey 的加密存储与轮换策略（现状为明文入库 + 掩码展示）。

### 1.4 关键约束

- 模型 ID 为唯一标识，创建后不可修改（编辑页展示为禁用）。
- ApiKey 在接口返回中始终为掩码值；提交值与掩码形态一致时视为未修改。
- 新增模型追加到列表末尾（按序号递增）。
- 模型删除不做事先引用校验，下游配置中的模型名将变为悬空取值。

## 2. 领域术语表

| 术语 | 定义 | 来源/约束 |
|---|---|---|
| 模型配置 | 一个可用模型的标识、端点与凭据集合 | 模型 ID 唯一 |
| 模型ID | 模型的唯一标识，同时作为下游引用的取值 | 创建后不可修改 |
| Anthropic BASE_URL | Anthropic 协议调用的服务端点 | 可空 |
| OpenAI BASE_URL | OpenAI 协议调用的服务端点 | 可空 |
| 前端 ApiKey | 浏览器侧调用使用的凭据 | 掩码展示，防误覆盖 |
| 后端 ApiKey | 服务端调用使用的凭据 | 掩码展示，防误覆盖 |
| 掩码值 | ApiKey 的展示形态：保留前 3 位与后 4 位，其余打码；长度不足 7 位时全打码 | 提交掩码值等于未修改 |
| 模型目录 | 全部模型配置的集合，供下游下拉选择 | 供 Agent 配置与通用Agent集成使用 |

## 3. 业务场景

- 场景描述：平台维护人员在接入新的模型服务时登记模型 ID、端点与两套 ApiKey，并选择默认模型；研发过程中调整 BASE_URL 或轮换 ApiKey。
- 触发条件：接入新模型服务、端点或凭据变更、清理不再使用的模型。
- 参与角色：平台管理员（维护）、Agent 配置人员（查看并使用）。
- 主流程：进入「环境管理 / 系统配置 / 模型配置」→ 新增模型配置 → 填写模型ID、名称、说明、BASE_URL 与前后端 ApiKey → 保存 → 在 Agent 配置或通用 Agent 集成中选择该模型。
- 分支流程：编辑既有模型（模型 ID 只读）；删除模型配置。

## 5. 能力规格（Capabilities & Expectations）

### CAP-M07-01 模型配置查看

- 目的：集中呈现平台可用的模型目录。
- 范围边界：只读展示；左侧模型列表、右侧模型详情。
- 关联规则：BR-M07-05、BR-M07-09
- 验收预期：
  - GIVEN 平台存在多个模型配置 WHEN 打开模型配置页 THEN 左侧按序号展示模型列表（模型ID + 名称），右侧默认展示首个模型的详情
  - GIVEN 查看模型详情 WHEN 查看 ApiKey 字段 THEN 展示掩码值而非明文，悬停提示「仅显示前3位与后4位；保持不变请勿修改，重新输入完整Key则覆盖原值」
  - GIVEN 平台无任何模型配置 WHEN 打开模型配置页 THEN 右侧展示空态「暂无模型配置」与引导「点击「新增模型配置」创建第一个模型」，左侧展示「暂无模型配置」
  - 异常预期：GIVEN 模型接口不可用 WHEN 打开页面 THEN 展示失败提示而非空态

### CAP-M07-02 新增模型配置

- 目的：把新的模型服务纳入平台模型目录。
- 范围边界：产生一条模型配置记录；不自动被任何 Agent 引用。
- 关联规则：BR-M07-01、BR-M07-02、BR-M07-03、BR-M07-04
- 验收预期：
  - GIVEN 未填写模型 ID WHEN 保存 THEN 拒绝并提示「模型ID不能为空」
  - GIVEN 模型 ID 与已有配置重复 WHEN 保存 THEN 拒绝并提示「已存在该模型ID的配置：X」
  - GIVEN 填写模型ID、名称、说明、BASE_URL 与 ApiKey WHEN 保存成功 THEN 该模型出现在左侧列表末尾，并可被 Agent 配置与通用 Agent 集成选择
  - 异常预期：GIVEN 保存失败 WHEN 提交 THEN 关闭新增态并提示失败原因，不写入本地列表

### CAP-M07-03 编辑模型配置

- 目的：修正模型端点、说明与凭据。
- 范围边界：模型 ID 不可修改；其余字段均可编辑。
- 关联规则：BR-M07-02、BR-M07-04、BR-M07-05、BR-M07-06
- 验收预期：
  - GIVEN 打开某个模型的编辑态 WHEN 查看表单 THEN 模型 ID 为禁用状态，其余字段回显当前值
  - GIVEN 仅修改名称或 BASE_URL WHEN 保存成功 THEN 详情展示最新内容，ApiKey 保持原明文
  - GIVEN 未改动 ApiKey 输入框（值仍为掩码） WHEN 保存成功 THEN 库中 ApiKey 明文不被掩码串覆盖
  - GIVEN 重新输入完整 ApiKey WHEN 保存成功 THEN 库中 ApiKey 被整体覆盖，展示为新的掩码值
  - 异常预期：GIVEN 模型 ID 不存在 WHEN 保存 THEN 提示「模型不存在：X」

### CAP-M07-04 删除模型配置

- 目的：清理不再使用的模型。
- 范围边界：只删除模型配置记录；不级联清理下游引用。
- 关联规则：BR-M07-08
- 验收预期：
  - GIVEN 某模型不再使用 WHEN 点击删除模型配置 THEN 该模型从列表移除并提示删除成功
  - GIVEN 模型仍被某 Agent 引用 WHEN 删除该模型 THEN 删除成功，Agent 的模型取值变为悬空值且不提示
  - 异常预期：GIVEN 模型 ID 不存在 WHEN 删除 THEN 提示「模型不存在：X」

### CAP-M07-05 模型目录供下游引用

- 目的：让 Agent 与集成配置共享同一份模型清单。
- 范围边界：只提供取值集合；引用关系由下游维护。
- 关联规则：BR-M07-07、BR-M07-10
- 验收预期：
  - GIVEN 模型目录存在多个模型 WHEN 打开 Agent 配置的模型下拉 THEN 选项与模型目录一致
  - GIVEN 模型目录存在多个模型 WHEN 打开通用 Agent 集成的默认模型下拉 THEN 选项与模型目录一致
  - 异常预期：GIVEN 模型目录为空 WHEN 打开下游下拉 THEN 下拉为空，不报错

## 6. 界面规格

### UI-M07-01 模型配置页

- 位置与入口：环境管理 / 系统配置 / 模型配置
- 页面标题与说明：标题「模型配置」；说明「维护平台可用模型的ID、名称、说明、ANTHROPIC/OPENAI BASE_URL与前端/后端ApiKey；Agent配置与通用Agent集成的模型选项均取自此页，预置：DeepSeek Pro、DeepSeek Flash、GLM、GLM Flash、QWen Max、Qwen Flash、GPT、Claude」
- 主操作：「新增模型配置」
- 元素清单：左侧模型列表（模型ID、名称、选中态、页脚「N个模型」）；右侧模型详情表单
- 交互规则：点击左侧模型切换右侧详情；点击新增进入新建态
- 状态与反馈：无模型时左右两侧均展示空态文案

### UI-M07-02 模型表单

- 位置与入口：右侧详情区
- 主操作：「保存模型配置」；新建态提供「取消」，编辑态提供「删除模型配置」
- 元素清单：模型ID（新建可填、编辑禁用）、名称、说明、ANTHROPIC_BASE_URL、OPENAI_BASE_URL、前端ApiKey、后端ApiKey
- 交互规则：ApiKey 输入框按掩码回显；保持掩码不变即视为不修改
- 状态与反馈：保存成功与失败均以浮动提示给出

## 7. 业务对象与属性

| 对象 | 关键属性 | 业务含义 | 必填 | 取值与约束 |
|---|---|---|---|---|
| 模型配置 | 模型ID | 模型唯一标识 | 是 | 最长 32 字符，全局唯一，创建后不可修改 |
| 模型配置 | 名称 | 模型显示名称 | 否 | 最长 64 字符 |
| 模型配置 | 说明 | 模型用途与适用场景 | 否 | 最长 256 字符 |
| 模型配置 | Anthropic BASE_URL | Anthropic 协议端点 | 否 | 最长 256 字符，可空 |
| 模型配置 | OpenAI BASE_URL | OpenAI 协议端点 | 否 | 最长 256 字符，可空 |
| 模型配置 | 前端 ApiKey | 浏览器侧调用凭据 | 否 | 最长 256 字符；接口只返回掩码 |
| 模型配置 | 后端 ApiKey | 服务端调用凭据 | 否 | 最长 256 字符；接口只返回掩码 |
| 模型配置 | 序号 | 列表展示顺序 | 是 | 整数，唯一且递增 |
| 模型配置 | 更新时间 | 最近修改时间 | 是 | 系统自动记录 |

派生展示信息（不单独存储）：模型数量、ApiKey 掩码值、下游下拉选项集合。

## 8. 依赖与复用关系

- 上游：无强依赖
- 下游：M10 Agent 配置（Agent 默认模型）、M08 通用Agent集成（默认模型与环境变量按模型维度配置）、M23 任务管理与流程执行（执行时使用模型）

## 9. 异常、边界与失败模式

| 场景 | 处理要求 | 关联能力/规则 |

| 删除仍被引用的模型 | 直接删除，下游取值悬空 | CAP-M07-04、BR-M07-08 |
